# Politique de confidentialité de Pong

Dernière mise à jour : 10 octobre 2026.

## Responsable et contact

Pong est un bot Discord personnel administré par dunzo.

Contact pour les questions de confidentialité et les demandes de suppression.

## Données consultées

Lorsque vous autorisez la fonctionnalité YouTube, Pong accède aux données nécessaires pour identifier votre profil YouTube et consulter vos vidéos aimées.

Les données utilisées comprennent :

- l’identifiant du profil ou de la chaîne YouTube autorisée ;
- les identifiants des vidéos aimées et leurs catégories ;
- l’identifiant du membre Discord associé ;
- les jetons OAuth nécessaires pour accéder à YouTube et renouveler cet accès.

L’outil d’autorisation consulte également le nom du profil YouTube afin de vous permettre de vérifier que vous avez sélectionné le bon profil.

Pong ne reçoit pas votre mot de passe Google.

## Utilisation des données

Ces données servent à détecter les nouveaux likes, appliquer le filtre choisi et éviter de publier plusieurs fois les mêmes vidéos.

Les jetons OAuth et le fichier d’état sont conservés sur le serveur du bot. Ils ne sont pas publiés sur ce site ni dans le dépôt GitHub.

## Partage dans Discord

Les liens des vidéos retenues sont envoyés dans le salon Discord configuré, avec une mention du membre associé.

Les membres ayant accès à ce salon peuvent donc voir les vidéos partagées et leur association avec ce membre.

Le partage n’est pas limité à l’utilisateur qui a donné son autorisation.

## Retrait de l’autorisation

Vous pouvez révoquer l’accès de Pong depuis les [paramètres de sécurité de votre compte Google](https://security.google.com/settings/security/permissions).

Cette révocation empêche les futurs accès autorisés à YouTube. Elle n’efface pas automatiquement les messages déjà publiés dans Discord.

## Demande de suppression

Vous pouvez contacter l’administrateur à l’adresse indiquée ci-dessus pour demander l’arrêt du partage et la suppression des données locales associées à votre compte.

Vous pouvez également demander la suppression des messages publiés par Pong.

La suppression des données détenues par Pong ne supprime pas vos likes ni vos vidéos sur YouTube.

## Services tiers

Cette fonctionnalité utilise YouTube Data API v3 et Discord.

Consultez également :

- la [politique de confidentialité de Google](https://policies.google.com/privacy) ;
- les [conditions d’utilisation de YouTube](https://www.youtube.com/t/terms).
